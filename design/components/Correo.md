# Correo electrónico
Correos impresos o capturados: cabecera con De · Para · Fecha · Asunto en `rotulo`, cuerpo en `pantalla`. Sirve para comunicaciones formales entre personajes (un notario, una empresa, un jefe).

- Direcciones ficticias con dominios inventados (`@horizontelabranza.cl`). Nunca un dominio real.
- Firma del remitente con cargo al pie del cuerpo. Un hilo de respuestas se muestra como dos componentes seguidos, el más reciente arriba.
