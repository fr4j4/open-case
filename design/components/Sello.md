# Sello
Sello de goma: texto en `display` (Barlow Condensed 700, mayúsculas, tracking .12em) dentro de un marco de doble línea, girado −6°. Dice una sola cosa y nunca más de tres palabras.

- Color por defecto `sello` (rojo). `--tinta` para sellos administrativos ("COPIA", "RECIBIDO"), `--laton` para la placa y los premios, `--bosque` para "VERIFICADO".
- `--esquina` lo fija abajo a la derecha de una `.oc-hoja` (como "EVIDENCIA N° 07"). `--grande` para portadas.
- Textos de la norma: RESERVADO (solo director), CASO ABIERTO, CASO CERRADO, EVIDENCIA N° __, COPIA, RECIBIDO, VERIFICADO, CONFIDENCIAL, PRUEBA DESCARTADA.
- Un sello por hoja como máximo. El sello nunca tapa texto que haya que leer.
